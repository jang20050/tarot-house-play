# 타로 하우스

문양 카펫 위에 펼쳐진 78장의 타로 중 세 장(과거·현재·미래)을 골라
오늘의 운세와 **지금의 나를 닮은 동물**을 알려 주는 브라우저 게임입니다.

## ▶ 바로 플레이

**https://jang20050.github.io/tarot-house-play/**

설치 없이 브라우저에서 바로 실행됩니다. [`index.html`](index.html)을 내려받아 더블클릭해도 인터넷 없이 동작합니다.

## 플레이 방법

1. 궁금한 주제를 고릅니다 — 오늘의 운세 · 연애운 · 대인관계 · 직업·학업운 · 금전운
2. 카드가 섞이면, 부채꼴로 펼쳐진 78장 중 마음이 가는 카드 3장을 고릅니다
3. 카드가 한 장씩 뒤집히고, 세 장의 기운을 합쳐 오늘의 한 줄 운세와 닮은 동물이 나타납니다
4. "카드 다시 섞기"를 누르면 매번 새로 섞인 덱으로 다시 시작합니다

## 동물은 어떻게 고르나요?

동물 31종은 사교성 · 에너지 · 사고방식 · 역할 · 적응력 · 표현의 6가지 성향 점수를 가지고 있습니다.
뽑은 카드의 의미도 같은 6가지 성향으로 점수를 매긴 뒤, 세 장을 합친 결과와 가장 닮은 동물을 보여 줍니다.
